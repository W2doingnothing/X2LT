# StashRat

[简体中文](README.zh-CN.md) · [Download for Windows](https://github.com/W2doingnothing/StashRat/releases/latest)

StashRat is a Windows desktop app for downloading and organizing a local media collection.

## Features

- Download images and videos from X likes or post links, and from Telegram channels, message links, or Saved Messages. Telegram supports incremental scanning.
- Pause and resume downloads, retry failures, and verify files with SHA-256.
- Import local images, videos, and comics. Browse, tag, search, group, and play media across multiple libraries.
- Move libraries while preserving their folder structure. Optionally store downloaded media in a single folder while keeping archive records in their original folders.
- Customize light and dark themes, accent colors, and four rat icons. Privacy mode blurs previews. Windows DPAPI protects saved credentials.

## Install on Windows

1. Download `StashRat-0.8.0-windows-x64.zip` from [GitHub Releases](https://github.com/W2doingnothing/StashRat/releases/latest).
2. Extract the entire ZIP to a folder on your computer. Keep the runtime folder beside `StashRat.exe`.
3. Open `StashRat.exe`. Install [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) if Windows reports it missing.

If you are upgrading from X2LT, close the old app first. StashRat uses your existing settings and library index.
