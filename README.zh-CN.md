# StashRat

[English](README.md) · [下载 Windows 版](https://github.com/W2doingnothing/StashRat/releases/latest)

StashRat 是一款在 Windows 上下载和整理本地媒体的桌面软件。

## 功能

- 从 X 点赞和推文链接，以及 Telegram 频道、消息链接和「我的收藏」下载图片与视频。Telegram 支持增量扫描。
- 支持暂停、断点续传、失败重试和 SHA-256 完整性校验。
- 导入本地图片、视频和漫画。支持多库管理、搜索、标签、聚合、播放和阅读。
- 按原目录层级迁移整库。支持自动脱壳，把媒体集中保存，归档记录留在原目录。
- 支持深浅主题、自定义主题色和四款鼠鼠图标。隐私模式可模糊预览，登录凭证由 Windows DPAPI 加密保存。

## Windows 安装

1. 在 [GitHub Releases](https://github.com/W2doingnothing/StashRat/releases/latest) 下载 `StashRat-0.8.0-windows-x64.zip`。
2. 完整解压到本地文件夹，保留 `StashRat.exe` 旁边的运行目录。
3. 双击 `StashRat.exe`。如果系统提示缺少 WebView2，请安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

从 X2LT 升级时，先关闭旧版程序。StashRat 会沿用已有的设置和媒体库索引。
